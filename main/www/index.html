Notifications

Pushes to Gotify, ntfy, Pushover, Telegram, or any webhook that takes a JSON POST — Home Assistant, n8n, Node-RED, Apprise. Detections found while patrolling are queued and delivered the next time the uplink is up — the SoftAP has no route to your server, so sending only works while joined to your network.

Network

Stored on the device, never in the repo. It is never sent back to this page, so the field stays blank even when a network is configured — leaving it blank keeps the stored password rather than replacing it. Tick open network only if there really is no password. While joined to a network the Wi-Fi sniffer is suspended — BLE scanning continues.

Ignored

Marks everything currently in range as known and resets the score. Prefers rules that survive address rotation — the advertised name, then the advert's shape, and only then the MAC. Use it somewhere you trust — it ignores detected threats too.
