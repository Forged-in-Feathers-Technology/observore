Observore

A passive counter-surveillance detector for the Seeed XIAO ESP32S3 and the dual-band ESP32-C5. It sits in one place, learns what is normally there, and reports what is new.

Two boards can share a chip and still need different firmware — a XIAO ESP32-C5 and a Waveshare C5 put different LEDs on the same pin, and only one of them has a UART bridge. The installer still checks the chip, so choosing a profile for the wrong chip is refused rather than flashed; this picker is for telling apart boards that share one.

This browser cannot talk to serial devices. Web Serial needs a Chromium-based browser on a desktop — Chrome, Edge or Opera. It does not exist in Firefox or Safari, and not on phones or tablets at all. This page must be served over HTTPS to reach a serial device.

Plug the board in over USB-C first. It appears as a serial device on its own — no driver, no button to hold. The right firmware is chosen from the chip it finds, so there is nothing to pick.

C5 boards have two USB-C ports: a native one and a UART bridge. Either flashes, and the log appears on both.

What this installs, and what it leaves alone

  • Your settings survive an upgrade. The bootloader, partition table and application are written at their own offsets, so the stored configuration is untouched — the mute rules, the Wi-Fi credentials, the notifier token and the device's console password all stay.
  • Tick “erase device” only if you mean it. That wipes the stored configuration, including the console password, and a new one is generated on the next boot.
  • Nothing is sent anywhere. The firmware is fetched from this page and written by your browser over USB. No account, no telemetry.

Straight after flashing: note the console password

Each device generates its own console password on first boot and prints it on the serial log — it is the only place it appears:

console SoftAP: "console-XXXXXX"  password: xxxxxxxxxxxx

Use Logs & Console on the button above to read it without any other software. It is both the Wi-Fi password for the device's setup network and the password that unlocks its web console, so it is worth writing down before you close this page.

Then

  • Hold the small BOOT button for 1.5 s. Join the console-XXXXXX Wi-Fi network with that password and open 192.168.4.1.
  • Enter your own Wi-Fi in the Network panel, then hold the button again to join it.
  • Leave it where it will live, let it patrol for ten minutes, and press Set baseline. After that it reports what is new rather than the whole neighbourhood.

The full walkthrough, and an honest list of what this device cannot see, is in the README.

Prefer a terminal?

Every release carries a bootloader, partition table and application for each supported chip, named with the target, plus a SHA256SUMS. The bootloader offset differs per chip, so these are not interchangeable.

# Seeed XIAO ESP32S3
esptool.py --chip esp32s3 -p /dev/ttyACM0 write_flash \
    0x0     bootloader-xiao-esp32s3.bin \
    0x8000  partition-table-xiao-esp32s3.bin \
    0x10000 ota_data_initial-xiao-esp32s3.bin \
    0x20000 observore-xiao-esp32s3.bin

# ESP32-C5-DevKitC-1 / Waveshare
esptool.py --chip esp32c5 -p /dev/ttyACM0 write_flash \
    0x2000  bootloader-devkit-esp32c5.bin \
    0x8000  partition-table-devkit-esp32c5.bin \
    0x10000 ota_data_initial-devkit-esp32c5.bin \
    0x20000 observore-devkit-esp32c5.bin
